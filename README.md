# 2026 日本夏日旅行｜互動地圖（完整行程版）

這是可直接上傳到 **GitHub Pages** 的純靜態網站，不需要安裝、資料庫或 API 金鑰。

## 本次修正

- 城市資訊面板已把 PDF 的逐頁詳細文字**直接完整展開**，不用再點開頁面。
- 保留景點玩法、時間、餐飲、交通、注意事項、備案與原來的各種建議。
- 每個城市新增 **Google Maps 地點連結**，詳細原文中辨識出的地名也能直接點擊 Google Maps 搜尋。
- **完全移除高千穗峽及相關路線**，包含地圖背景的圖示、城市按鍵以及舊版行程文字。
- **7 月 29 日：宮崎直接開車返回福岡**，不沿用取消路線原本的行車時刻。
- 原始 PDF 不直接公開附在網站中，因其內含預約資料及已取消的舊方案。

## 部署 GitHub Pages

1. 建立 GitHub repository，並上傳 `index.html`、`itinerary.json` 和 `assets/map-clean.jpg`，保留資料夾結構。
2. 前往 **Settings → Pages → Build and deployment**。
3. 選擇 **Deploy from a branch**，再選擇 `main`、`/ (root)`。
4. 開啟 GitHub Pages 顯示的網址。

## 注意

- Google Maps 採**地點文字搜尋**，搜尋同名地點時請確認地圖結果。
- PDF 有不同的備選路線、跨頁續文和舊時刻，除最新明確取消的路線外，其他筆記盡量照原文保存。
- 原 PDF 的票價、營運時間及班次可能已變動，請以營運商公告為準。
- 首頁與個別城市頁都有搜尋功能，支援桌面和手機。
